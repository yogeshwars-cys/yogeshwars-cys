# Hi, I'm Yogeshwar S 👋

I build research-driven systems at the intersection of **AI, security, distributed systems, and applied engineering**. I enjoy turning difficult technical ideas into prototypes that can be tested, measured, and explained.

## Featured projects

### 🔐 [VAULT — Private AI Environment](https://github.com/yogeshwars-cys/iqoo-hackathon)
A phone-first private AI coprocessor concept: documents stay on-device, retrieval happens locally, and answers are returned as signed capsules that a laptop can verify.

### ✈️ [Turbojet Digital Twin](https://github.com/yogeshwars-cys/turbojet-digital-twin)
A physics-informed engine digital twin for estimating hidden component health, predicting performance, and exploring degradation through an interactive dashboard.

### 🛡️ [Pramana — AI Risk Manager](https://github.com/yogeshwars-cys/Pramana-AI-Risk-Manager)
A distributed fraud-risk concept designed to share privacy-preserving signals across merchants while keeping consequential enforcement grounded in first-hand evidence.

### 🧠 [Neuromorphic Primitives](https://github.com/yogeshwars-cys/neuromorphic-primitives)
A Python library exploring neuron-like computational primitives, adaptive thresholds, and spike-based behavior.

### 🌐 [Autonomous Neighbourhood Watch](https://github.com/yogeshwars-cys/Autonomous-Neighbourhood-Watch-ANW-)
A research project exploring local observation and peer-to-peer coordination for decentralized situational awareness.

### 🧪 [AI Security Workshop Console](https://github.com/yogeshwars-cys/Ai-sec)
A local workshop environment for hands-on AI red-teaming across several vulnerability classes.

## How I like to build

- **Evidence over hype:** document assumptions, measurements, and limitations.
- **Safety by design:** make trust boundaries and failure modes explicit.
- **Useful explanations:** make architecture and trade-offs understandable.
- **Reproducibility:** provide clear setup steps and a path to verify results.
